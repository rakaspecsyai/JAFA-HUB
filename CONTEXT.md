## Status dan keputusan setelah audit

- Fondasi, autentikasi, CMS dan portal sudah mempunyai implementasi lokal. Ini bukan klaim semua kebutuhan produksi diterima. Nomor tahap mengikuti PRD §17; jangan memakai label lama “tahap 3 = E2E” sebagai gerbang coding tanpa batas.
- Paket aksesibilitas yang sudah lulus tetap menjadi bukti. Buka kembali hanya karena perubahan terkait, cacat yang dapat direproduksi atau kebutuhan baru. Pemeriksaan manual tetap gerbang rilis dan tidak diganti dengan mengulang screenshot/zoom lokal.
- Audit menemukan dua celah fungsi: filter daftar memakai sembarang revisi histori, dan kanal Kontak URL/email/telepon beserta jam layanan PRD §13.1 belum mempunyai model/editor. **Paket A selesai lokal:** 21 unit, 49 integrasi, 4 browser terarah, typecheck dan build lulus. Tidak ada klaim suite penuh 56 kasus telah diulang.
- **Paket B: pemulihan CMS FR-18 selesai lokal.** `ActionState/publicError` membawa status; pesan 401/403/409 menyediakan masuk kembali, pemeriksaan akses atau pembandingan di tab baru. Masukan dan versi lokal tidak diperbarui otomatis. **22 unit, 50 integrasi, 4 browser terarah, typecheck dan build lulus** pada paket itu.
- **C1 dan C2 selesai lokal.** Bukti C1 tetap hasil 10 November: 25 unit, smoke, migrasi/impor/restart native dan 29 materi tetap draf. **C2 pada 11 November: pemeriksa native HTTPS exit 0, typecheck dan build image lulus.** Login/sesi, tiga peran, penolakan persetujuan sendiri setelah perubahan peran, publikasi/penarikan dan media bersama terbukti pada fixture baru. Suite PGlite lama tidak diulang.
- Perintah `docker` Linux masih menunjukkan integrasi WSL belum tersedia pada pemeriksaan 10 November, tetapi CLI Windows `docker.exe` dapat mengakses engine Linux melalui named pipe lokal. C1 memakai jalur itu dengan project uji unik; container/network/volume uji sudah dibersihkan. Hosting/staging resmi dan petugas belum ditetapkan; tidak ada layanan eksternal, akun nyata, domain atau biaya yang diaktifkan.
- **Jalur RAG disetujui paralel dengan C2, beta setelah evaluasi.** Sumber MVP adalah PDF resmi undang-undang/peraturan Jabatan Fungsional yang akan diunggah pengguna. Pengguna kemudian mengganti jawaban anggaran Rp0 untuk AI: memilih API hosted karena tidak menyediakan hardware model lokal, dengan biaya serendah mungkin. Jangan kembali memilih model lokal atau menganggap batas biaya AI tetap Rp0. Anggaran infrastruktur lain tidak otomatis berubah.
- Rancangan R1 di [PRD-RAG-Jafa-Hub.md](docs/PRD-RAG-Jafa-Hub.md). Rekomendasi awal, belum pilihan pengguna: GPT-6 Luna + text-embedding-3-small; sekitar US$0,55–0,63/1.000 pertanyaan pada asumsi 3.000 input/500 output berbayar, embedding pertanyaan 100 token, serta input biasa atau cache-write 30 menit. Tambahkan US$0,02/1 juta token embedding dokumen awal. Usulan batas pilot US$5/bulan belum ditetapkan; harga resmi ditinjau 11 November dan bukan benchmark. PDF, key, akses model dan evaluasi belum tersedia. Tidak ada panggilan model berbayar, install model/extension, migrasi atau aktivasi chatbot AI pada R1.

Artefak privat `.local/cms-recovery-20261110-jploiaut/` menyimpan sumber/dokumen awal, baseline, log dan `e2e/`; trace dapat memuat kredensial/sesi sintetis. Data/cadangan pengguna, `.env`, skema tabel, dependensi serta aturan peran/persetujuan tidak diubah.

Syarat paket yang telah tercapai:

1. Bedakan sesi habis/akses/konflik pada hasil Server Action tanpa membuka detail internal.
2. Sesi habis menyediakan masuk kembali tanpa meninggalkan masukan editor; sesudah login pengguna dapat mencoba ulang.
3. Konflik menyediakan akses ke versi tersimpan untuk dibandingkan, mempertahankan masukan lokal dan tetap menolak versi basi; tidak ada penimpaan otomatis.
4. Verifikasi dua alur nyata dengan fixture terisolasi dan batas paket tersebut. Unit/integrasi/browser dipilih sesuai perubahan; jangan membuka ulang semua variasi lama tanpa alasan baru.

**Berikutnya R2b:** indeks/retrieval setelah korpus privat R2a, sesuai PRD tambahan. PDF pengguna belum diterima; provider/cap/key tetap belum final dan tidak ada API berbayar diaktifkan. Untuk staging resmi, pengguna/petugas tetap menetapkan host, origin HTTPS dan konfigurasi privat. Exception development `Performance.measure` perlu diagnosis bila terbukti mengganggu alur inti; jangan mengganti dependensi atau menekan error tanpa reproduksi.

**Paralel RAG:** R1 sudah berupa rancangan untuk ditinjau, dengan sumber PDF dan arah API cloud diputuskan pengguna. Model/vendor, batas nominal dan kebijakan provider belum final. R2a sudah menyediakan ingest PDF privat dan persetujuan; R2b menyelesaikan indeks/retrieval; jangan memasukkan PDF draf, materi prototipe atau dokumen internal ke AI publik otomatis. PDF tidak memakai endpoint gambar `/api/media`. R3 generasi/kutipan/batas biaya baru diaktifkan setelah sumber/key/cap siap, R4 evaluasi substansi sebelum beta. Tidak mengubah portal inti menjadi bergantung pada peluncuran RAG.

## Data dan batas yang wajib dipertahankan

- Jangan hapus `.local`, mengganti database pengembangan dengan database kosong, mengulang bootstrap, atau menjalankan skrip pemulihan lama untuk setup. Direktori ini menyimpan data dan cadangan pengguna.
- PGlite lokal hanya boleh dibuka satu proses. Gunakan harness kode/cache serta database/media terisolasi; jangan memakai `.next`, `.env`, sesi atau data pengguna untuk tes.
- Better Auth dan migrasi tata kelola pada database lama sudah diselesaikan pada 26 Oktober; jangan mengulang maintenance itu. Akun/hash/ID dan materi dipertahankan; rincian dan batas ada di arsip.
- Impor tetap draf; jangan membuat akun nyata atau menerbitkan materi pengguna untuk verifikasi. Publikasi fixture uji bukan persetujuan substansi.
- Pembaca layar/perangkat nyata, audit aksesibilitas/keamanan independen, konfigurasi host/proxy resmi, performa/backup-restore staging, UAT, nomenklatur/sumber/simulator/kontak/privasi serta persetujuan produksi tetap terbuka. Jangan mengisi kelulusan dari hasil otomatis.
- Skill agen (tooling lokal, bukan bagian produk): salinan kanonis 19 skill ada di `.agents/skills/` dan dikunci `skills-lock.json`; hash folder cocok dengan lock pada 13 November 2026.
