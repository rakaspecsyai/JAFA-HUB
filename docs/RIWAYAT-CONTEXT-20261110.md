## Menjalankan dan mengelola data

```bash
npm run dev -- --port 5174
```

Alamat pratinjau sesi sebelumnya: http://localhost:5174. Periksa apakah server masih aktif sebelum menjalankan lagi. Launcher dev menyiapkan environment/database dan mengimpor draf bila diperlukan. Petunjuk instalasi lengkap ada di `README.md`.

- `JAFA_CONTENT_PREVIEW=true` hanya untuk pengembangan: portal menampilkan fixture prototipe dengan banner, sehingga perubahan CMS tidak mengganti materi pratinjau.
- Untuk menguji publikasi dari database, gunakan `JAFA_CONTENT_PREVIEW=false`, mulai ulang server, lalu jalankan alur editor/penyetuju. Produksi selalu mematikan pratinjau.
- Database yang dipulihkan sudah berisi tiga akun dengan peran editor, penyetuju, dan admin. Akun lokal ini tidak membuktikan penunjukan petugas UAT/produksi. Jangan mengulang bootstrap untuk memperbaiki startup. Perintah `npm run admin:bootstrap -- --email "<email-petugas>" --name "<nama-petugas>"` hanya untuk instalasi yang memang belum mempunyai admin aktif; hentikan dev sebelumnya.
- Satu proses saja boleh membuka database PGlite lokal; kunci antarproses kini menegakkan aturan bagi pemanggil proyek. Hentikan dev sebelum bootstrap/impor/backup dalam proses lain. Kunci asing/tidak dikenal ditolak tanpa dihapus otomatis. Jangan hapus `.local` jika data ingin dipertahankan; ikuti `docs/DATA-LOKAL.md` untuk salinan dan pemulihan.
- Lingkungan pengerjaan sebelumnya memerlukan `PRISMA_SCHEMA_ENGINE_BINARY=.local/schema-engine` untuk menghindari akses tulis ke cache global read-only; periksa konfigurasi lokal jika Prisma gagal dengan EROFS.

WAL tidak direset; tabel tidak dikosongkan. Setelah verifikasi, hasil dipasang kembali di `.local/development-pg`; `.env` dan kode aplikasi tidak diubah.
